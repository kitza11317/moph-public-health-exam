# MOPH CBT — ข้อสอบชุดที่ 1

เวอร์ชันนี้ประกอบด้วยข้อสอบนักวิชาการสาธารณสุข 100 ข้อที่เขียนใหม่ทั้งหมด ไม่ใช้วิธีดัดแปลงคำถามเดิมหลายเวอร์ชัน

## คุณสมบัติ
- ข้อสอบ 100 ข้อไม่ซ้ำ
- ตัวเลือก 4 ตัวเลือกที่ออกแบบให้ใกล้เคียงและต้องใช้การวิเคราะห์
- เฉลยและคำอธิบายทุกข้อ
- ระดับความยาก: ปานกลาง 30 ข้อ, ประยุกต์ 45 ข้อ, ยาก 25 ข้อ
- ครอบคลุม 18 หมวดตาม Blueprint
- สุ่มลำดับข้อและตำแหน่งตัวเลือก
- จับเวลา 180 นาทีและบันทึกคำตอบอัตโนมัติ
