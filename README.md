# MOPH CBT — คลังข้อสอบชุดที่ 1–2

เวอร์ชัน 5.0 รวมข้อสอบนักวิชาการสาธารณสุข **200 ข้อ** ได้แก่ชุดที่ 1 และชุดที่ 2 ชุดละ 100 ข้อ

## ข้อสอบชุดที่ 2
- เขียนใหม่ 100 ข้อ ไม่ใช้การเปลี่ยนถ้อยคำจากชุดที่ 1
- ตัวเลือก 4 ตัวเลือกที่ใกล้เคียงและต้องใช้การวิเคราะห์
- เฉลยพร้อมเหตุผลทุกข้อ
- ครอบคลุม 18 หมวดตาม Blueprint
- ระดับความยาก: ยาก 44 ข้อ, ประยุกต์ 39 ข้อ, ปานกลาง 17 ข้อ

## การเลือกชุด
หน้าเข้าสู่ระบบเลือกได้ 3 แบบ:
1. สุ่มจากชุดที่ 1–2
2. ทำเฉพาะชุดที่ 1
3. ทำเฉพาะชุดที่ 2

## อัปเดต GitHub Pages
อัปโหลดไฟล์ทั้งหมดทับไฟล์เดิม แล้วเปิด URL เดิมพร้อม `?v=50` เพื่อบังคับรีเฟรชแคช

## ไฟล์ข้อมูล
- `questions-set-1.json` — ชุดที่ 1
- `questions-set-2.json` — ชุดที่ 2
- `questions-all-200.json` — รวมสองชุด
- `questions.js` — คลังที่เว็บไซต์ใช้งาน
