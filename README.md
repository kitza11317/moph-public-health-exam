# MOPH CBT Simulation v3

เว็บจำลองสอบนักวิชาการสาธารณสุข รองรับ Safari/มือถือ และ GitHub Pages

## ไฟล์ที่ต้องอัปโหลด
อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ไว้ที่ root ของ repository แล้วเปิด Settings > Pages > Deploy from a branch > main / root

## คุณสมบัติ
- คลัง 500 รายการ (100 แนวคิดหลัก × 5 รูปแบบสถานการณ์)
- สุ่ม 100 ข้อและสุ่มตัวเลือกในโหมดสอบจริง
- จับเวลา 180 นาที / ส่งอัตโนมัติ
- Auto-save, ทำเครื่องหมาย, ไปข้อที่ยังไม่ตอบ
- คะแนนทันที เฉลย วิเคราะห์รายหมวด ประวัติย้อนหลัง
- PWA และรองรับมือถือ

หลังอัปโหลดให้เปิด URL พร้อม `?v=3` หนึ่งครั้งเพื่อเลี่ยงแคชเก่า
