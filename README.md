# ข้อสอบจำลองนักวิชาการสาธารณสุข v2

ไฟล์ที่ต้องอัปโหลดขึ้น GitHub Pages ให้ครบทั้ง 4 ไฟล์:
- index.html
- style.css
- script.js
- questions.js

## วิธีอัปเดต Repository เดิม
1. เปิด Repository `moph-public-health-exam`
2. ลบหรือแทนที่ไฟล์เดิม
3. อัปโหลดไฟล์ทั้ง 4 ไฟล์จากชุดนี้ไว้ที่ root ของ branch `main`
4. รอ GitHub Pages deploy 1–3 นาที
5. เปิดหน้าเว็บใหม่ และรีเฟรช Safari

หาก Safari ยังจำไฟล์เก่า ให้เปิดลิงก์ใน Private Browsing หรือเพิ่ม `?v=2` ต่อท้าย URL หนึ่งครั้ง
